# Contributing to tidewater

## Commit messages

We use Conventional Commits: `type(scope): subject`. A `!` after the type or scope, or a
`BREAKING CHANGE:` footer in the body, marks a breaking change.

## Versions

We follow semver. While we are below 1.0.0, a breaking change bumps the minor version
(0.4.2 → 0.5.0) and everything else bumps the patch version.

## Credits

Every release credits the people who worked on it, by name, in alphabetical order. That includes
anyone in a `Co-authored-by:` trailer. People, not bots. If someone has committed under more than one
name or email, `.mailmap` says which name to use.
